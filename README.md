## Build it. Break it down. Go deeper.

I'm **harnakam**, a developer and student exploring the space between **systems engineering, interactive graphics, and AI**.

I build game clients, developer tools, and web experiences—and take systems apart to understand what makes them work. My interests reach from rendering pipelines and reverse engineering to relationships in data and language models beyond Transformers.

**仕組みを解き、体験をつくる。低レイヤーから、光が動くインターフェースまで。**

## 01 / Rebuilding the familiar

### Minecraft 1.8.9 → a modern Java & graphics stack

Rebuilding the client with **JDK 25**, **Gradle 9.5.1**, and **LWJGL 3.4.1**. Working with **GLFW + OpenGL** for rendering and **Ultralight** for UI.

An ongoing exploration of game clients, rendering, and how the pieces of an interactive system fit together.
